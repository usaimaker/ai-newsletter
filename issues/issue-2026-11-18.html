AI Automation Daily - November 18, 2026

Today's theme: the model is no longer the product. The plumbing around it - routing, tool calls, caching and proof - is where the money is saved. Five fresh findings you can put to work this week.

1. Microsoft Decision 1.1: route small jobs to a 1/200-cost model

At Ignite 2026, Microsoft made Decision 1.1 generally available: a decision model built on Google's Gemma 4 26B A4B mixture-of-experts model. Instead of writing long answers, it picks from fixed options or assigns scores - exactly what classification and routing need. Microsoft claims it is more than 10x faster than using an LLM and about 1/200 the cost. Practical move: split your agent pipeline into a decide stage and a write stage. Send triage, tagging and tool selection to a decision model, and reserve the frontier model only for work that genuinely needs prose.

2. Code mode cuts MCP tool-call tokens by 70-90%

A pre-registered study (arXiv:2611.19123, Nov 14) compared plain MCP JSON calls against code mode, where the agent writes a script against tool stubs and only the final result re-enters context. On a sealed split with up to 1,958 distractor tools, code mode used 70-90% fewer tokens and improved utility for two of three open-weight agents. The surprise: declaring return-shape hints in the stubs moved success by up to 39.5 points - a bigger effect than adding a router. Caveat: the test world was synthetic. Use a bounded fallback, measure latency, and never let an unbounded router retry loop run on production traffic.

3. AWS: page large JSON to S3 and cut tokens per turn by 71%

AWS described a production pattern for Bedrock AgentCore agents handling large JSON: offload results to S3 and load only the pages you need, with dictionary compression on top. Reported result: up to 71% fewer tokens per turn and up to 80% lower latency. Separately, SageMaker AI real-time endpoints now route each request to the instance holding the longest prompt-cache match, while ArisGlobal cut monthly inference spend about 40% by caching a shared prompt prefix. If your agent re-reads the same big payload every step, stop paying for it twice.

4. Gemini 4 Hydrogen + Orchestrator: cheap execution, automatic routing

Google's Gemini 4 Hydrogen (Nov 12) is built for agent execution, not deep reasoning: $1.50 / $7.50 per million tokens flat across a 1M context, cached input at $0.075, 2.5x faster than the 3.8 Flash it replaces, and 57% on Terminal-Bench 4.1 versus 18.2%. In Antigravity, Orchestrator routes each step between heavy Carbon and fast Hydrogen: near-Carbon success while using 24% less quota and finishing 19% faster. The lesson is model-agnostic: plan with the expensive model, execute and verify with the cheap one.

5. Genesys puts agents behind effort-based pricing

On Nov 18, Genesys launched Standalone AI Agents and Genesys Arena, letting companies add agents to existing contact-center systems in days. Arena ships 50+ industry Agent Kits that produce a working agent in as little as 10 minutes. Pricing shifts from seats and tokens to Experience Units tiered as simple, moderate or complex - you pay for the work actually done. Whether or not you buy it, the design is worth copying: scope one task, keep a human handoff with full context, and budget by task complexity rather than by seat.

Automation tip of the day: Stop paying to re-think. Decide with a decision model, call tools with code mode plus return-shape hints, execute with the cheapest model that passes your tests, and page or cache any payload you read more than once. Put a per-run cap and a human approval gate on anything that spends money or changes production state.
