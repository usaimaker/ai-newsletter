Five fresh moves from early November 2026 that directly cut your AI bills or your to-do list. No hype - just what changed and what to do about it.

$0.10/MMeta Muse Ember: a $0.10-per-million executor for your agent herd

Launched November 9, Muse Ember is Meta's lightest model and its first built specifically as an agent execution layer. Priced at $0.10 / $0.50 per million in/out (cached input just $0.004/M) with a 1M-token context and multimodal input (text, images, audio, video), it is designed to do the repetitive volume work - tool calls, routing, document extraction, small code fixes - while a bigger model plans. Meta's demo ported 16 Python to Rust lexers in parallel for about $3.96 total. Route your high-frequency agent steps here instead of a frontier model and the savings compound across every run.

-90%Perplexity Agent API: cheaper research, new ultra tier

Announced November 5, every effort level in Perplexity's Agent API now costs less per query with equal or better quality. The headline: medium jumped from 55% to 77% on BrowseComp/DSQA while its cost fell almost 90%; xhigh runs at about 25% of its August price. A new ultra tier fans one research problem across three parallel agents plus a consolidator (85.9% WANDR at $21.71/task). If you run agentic research or data-collection loops, repoint them at the lower tiers and let the budget caps stop runaway tool-call chains.

TIMEAWS prompt caching for OpenAI on Bedrock trims agent loops

AWS published guidance for prompt caching on OpenAI models running on Amazon Bedrock. Agent loops resend the same system prompt and background context on every step, which silently balloons cost and latency. Caching that static context means each turn pays for only the new tokens. If your agents repeat long instructions or large knowledge blobs every call, turn on caching and watch both bill and wait time drop on long-running automations.

BROWSERLangChain Managed Deep Agents v0.10: browser use + background subagents

LangChain shipped Managed Deep Agents v0.10 with two practical additions: browser use (so an agent can drive sites with no API) and async background subagents (a main agent hands off long jobs and keeps moving instead of blocking). That means one orchestrator can now watch a site, kick off research in the background, and return to the user faster - less waiting, fewer wasted cycles, and broader task coverage without writing custom scrapers.

SALESxAI Shared Bots: three bots that run your deal cycle

xAI introduced Shared Bots for sales teams - Account Intel Bot, Quote Bot, and Deal Bot - that automate parts of the deal cycle: researching an account, preparing quotes, and tracking deals across the whole team. Instead of stitching separate prompts and CRMs, a shared bot handles the busywork so reps spend time closing. Point it at your pipeline and let the repetitive research-and-quote steps run themselves.

Automation tip of the day: Split your stack into a planner plus a herd of cheap executors. Muse Ember, Perplexity's cheaper tiers, and Bedrock prompt caching all reward routing repetitive steps - tool calls, extraction, classification - to the smallest model that still clears the bar. Keep one strong model for planning, run the volume on $0.10/M workers, and set a hard per-run budget and kill switch so a loop can never run away.
