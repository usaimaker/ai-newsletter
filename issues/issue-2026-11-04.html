Open Source DeepSeek open-sources its Super-agent base (MIT)

DeepSeek's Harness team released dsh-superagent under MIT on Oct 31. It splits an agent into a always-on Router (receives messages from IM, GitHub, email) and parallel Workers that each keep their own context. In internal use it proactively spots bugs in group chats and files fix PRs without being @-mentioned. Median task time dropped to 12.4 min vs 29.5 min for single-session setups. Free to self-host — skip the per-token bill entirely for background coding ops.

github.com/deepseek-ai/dsh-superagent-prototype

Computer Use Vercel agent-desktop: control the desktop without screenshots

Vercel Labs open-sourced agent-desktop, a Rust CLI + C library that lets coding agents read and drive desktop apps through the OS accessibility tree instead of screenshots. It runs on macOS, Windows and Linux, and on complex Electron apps it cuts token usage by 78–96%. If your agents currently "look" at the screen via image captures, this swaps a huge cost driver for a cheap text stream.

vercel.com/blog/agent-desktop

Cost Cut TokenEconomizer compresses agent context 18–31%

Microsoft Research + UC Berkeley open-sourced TokenEconomizer, which learns from a repo's past sessions and trims redundant context before each run. Across 277 SWE-Bench tasks and five agent/model combos it lowered average cost by 18.4% to 30.9%. It plugs into Claude Code, Codex, GitHub Copilot CLI and Pi. Best for teams with a continuous, single-repo history to learn from.

github.com/microsoft/TokenEconomizer

Lesson LinkedIn held AI cost flat by distilling small models

LinkedIn revealed its AI hiring assistant now serves 25,000+ paying companies while compute cost stayed flat year-over-year — by replacing most OpenAI calls with distilled lightweight models for candidate search, ranking and outreach messaging. Savings reached 67% versus a year ago on those steps. Takeaway: for narrow, high-volume automation tasks, a small fine-tuned model beats a frontier API call on both price and latency.

finance.sina.com.cn · LinkedIn cost story

Coding Agent Factory Droid 1.0: model-independent harness

Factory shipped Droid 1.0, a coding-agent framework that is not tied to any single model — the model itself writes the program and can fire hundreds of tool calls in one request. Its base prompt is 37% smaller, and Factory reports a higher pass rate than other harnesses it tested on the same model. Portable across models, so you can chase the cheapest capable option without rewriting your pipeline.

factory.ai/blog/droid-1-0

Automation tip of the day

Kill the screenshot tax. If your computer-use agents capture the screen as images, you are paying for thousands of vision tokens per action. Switch to an accessibility-tree driver (Vercel agent-desktop style) — it cut token use 78–96% on Electron apps. Stack it with a context compressor like TokenEconomizer for another 18–31% off your runs. Two changes, one afternoon, double-digit percentage savings on every agent hour.
