Issue 2026-11-13 - Friday

This week the agent stack finally split into roles with real price tags. The headline: you can now run the repetitive 95 percent of agent work on a model that costs a tenth of a cent per million tokens - and keep the expensive frontier model only for the steps that actually need it.

CHEAP EXECUTORMeta Muse Ember: a $0.10/M worker for the boring 95 percent

Meta launched Muse Ember on November 9 as the execution layer of its Muse family - priced at $0.10 per million input and $0.50 per million output tokens, with cached input at just $0.004. That is roughly 1/80th the per-token price of Anthropic Fable 5.2 and about a third of the cost-per-task of Claude Haiku 5.5 on the Artificial Analysis index.

Ember is built for the steps an agent repeats hundreds of times a day: tool calls, routing, data extraction, test runs, and long-document parsing. Meta demoed porting 16 code lexers from Python to Rust - Wonder planned, 16 Ember agents ran in parallel - for about $3.96 total, with $1.84 of that Ember. Early partners (Cloudflare, You.com) report 30 percent faster tail latency and 36 to 48 percent fewer output tokens than the model they replaced.

Money move: route every high-volume, low-complexity agent step to Ember instead of your flagship. Keep a stronger model for planning only.

FRONTIERGemini 4 Carbon goes GA - and brings /swarm

Google made Gemini 4 Carbon generally available on November 10 at an introductory $2/$10 per million tokens (doubles to $4/$20 after November 30). It tops the Artificial Analysis index and leads on security work, though it trails Claude Opus 5.5 on desktop computer use.

The bigger automation story is /swarm in Google Antigravity: one prompt spins up a coordinated team of agents with isolated parallel workspaces, role assignment, and adversarial verifiers that test each change. That is orchestration as a first-class feature, not something you hand-wire yourself.

Money move: Carbon intro rate is half of most flagships through month-end - a cheap window for long-horizon reasoning jobs before the price lift.

FREE OUTPUTGemini Decisions API: pay $0 for output on classification

Google shipped the Gemini Decisions API on November 11, powered by the new Gemini Decision 1 model. One request takes one input and up to 1,000 independent yes/no or closed-set questions, priced at $0.10 per million input tokens and $0 for output tokens. Google says that is nearly 5x cheaper than Gemini 3.5 Flash-Lite on its benchmark suite.

Money move: any workflow that ends in a routing or classification decision - triage, tagging, intent detection - can offload that step here and pay nothing for the answer tokens.

GOVERNEDDatabricks Genie: an autonomous coworker with a spending cap

Databricks launched the new Genie on November 11: an agent that takes long-running jobs by email, Slack, or Teams, follows up when inputs are missing, and runs on schedules or triggers (like a dipping metric). It operates under the user own identity, sees only what that user can see, and records every action.

The part procurement teams care about: admins set per-user budgets, spending caps, and alerts. Databricks reports Genie answered correctly in 91 percent of runs on a Turing-built benchmark.

Money move: an agent you cannot put a spending limit on will not pass a CFO. If you deploy autonomous agents, require a hard per-run budget before anything ships.

LOCAL TESTAWS Emulator: test cloud code locally, written by agents

Amazon released AWS Emulator on November 11 - a local emulator of AWS services that, per Amazon, was written entirely by autonomous agents. You do not need an AWS account, and there is an aws-emulator skill for AI coding agents so your agent can test against mocked AWS services offline.

Time and money move: stop burning a cloud account (and its bill) to test agent-built infrastructure code. Run it locally first, free, then promote to real AWS once it passes.

Automation tip of the day

Build a 3-layer cost defense, not a single model. (1) Model ladder - plan with a frontier model, execute the boring 95 percent on the cheapest worker (Ember at $0.10/M, or the Decisions API at $0 output). (2) Prompt cache - cache stable system prompts and repo context so repeats cost a fraction. (3) Hard budget cap - like Databricks Genie, set a per-run dollar ceiling and a kill switch so a runaway loop cannot quietly drain the account. Most agent overspend is one forgotten loop, not one expensive call.
