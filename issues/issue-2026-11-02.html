1. DeepSeek Super-agent goes open-source: a free Claude Code rival

COST + TIME

DeepSeek released Super-agent on October 31 as an MIT-licensed research prototype on GitHub. It uses a router-worker design: a router keeps shared context and assigns tasks, while isolated workers run in parallel and return results. It can watch a GitHub repo and developer chats, spot issues on its own, and open pull requests without being asked. For teams this is a free, self-hostable alternative to paid coding agents, and it directly attacks the real bottleneck: human attention. One engineer can only track a few agent sessions at once, so parallel workers that need less supervision save real time. The published repo drew thousands of stars in its first day. Practical move: clone it, point it at a low-risk repo, and let it triage issues while you review.

2. Microsoft open-weights 4B computer-use model

COST

Microsoft published Mage-VL-Cowork, a four-billion-parameter computer-use model under the Apache 2.0 license. It switches between screen interaction and terminal commands and reports a 66 percent score on 361 OSWorld-Verified tasks. Because the weights are open, you can run it on your own hardware instead of paying per call for a hosted agent. For repeatable desktop automation such as form filling, report downloads, and data entry, a self-hosted model removes the per-task API bill. The catch is setup effort, and the benchmark is developer-run, but for teams with steady GUI work the math favors owning the model.

3. DeepSeek Search and Fetch now billed at 0.75 dollars per 1,000 calls

COST

The free exemption for DeepSeek server-side Search and Fetch calls ended on November 1. Each API now costs 0.75 dollars per 1,000 successful requests, separate from token charges. Failed requests, empty results, and timeouts are not billed. The lesson for agent builders: retrieval is no longer free, so budget for tool calls, not just tokens. DeepSeek Flash stays among the cheapest capable models, so pair cheap calls with cheap models. Add a per-run cap on tool calls so a chatty agent cannot quietly run up the bill.

4. Particle-1: 38 percent fewer tokens at 0.25 dollars in, 1 dollar out

COST

Particle AI launched Particle-1 on October 28, a small fine-tune of DeepSeek V4.1 Flash that does the same coding work with about 38 percent fewer output tokens. Its card is 0.25 dollars input, 0.03 cached, 1 dollar output, and half that from 20:30 to 04:00 New York time. Run heavy coding jobs in the off-peak window and a task that costs 0.14 dollars at peak drops toward 0.07 dollars. The takeaway: a lighter model plus off-peak scheduling can beat a bigger model on price without losing the result.

5. Figma October 29 report: agent 20 percent faster, 60 percent fewer undos

TIME

Figma published an October 29 engineering report showing typical agent tasks became about 20 percent faster between beta and general availability, with 33 percent higher user ratings and 60 percent fewer undos. The gains came from changes across models, tools, and the agent system, not one magic model. For design and product teams, a faster agent means less waiting and less cleanup after each run. The broader signal: specialized agents tuned to a workflow beat generic ones, so invest in tooling that fits your actual steps.

Automation tip of the day

Budget tool calls, not just tokens. With DeepSeek now billing search and fetch per call and Particle pricing by time of day, the old habit of counting only tokens misses real cost. Add a per-run cap on tool calls, shift heavy agent runs to off-peak windows, and route retrieval to the cheapest model you trust. A chatty retrieval agent can spend more on calls than on text, so measure both and cap both.
