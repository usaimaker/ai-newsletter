AI Automation Daily - November 21, 2026

Today's theme: stop paying a general model to do the small, frequent jobs. The freshest savings come from letting the API fetch only the tools it needs, using a sub-cent decision model for the split-second choices, and running agents on the AI you already pay for. Five practical findings you can put to work today.

1. Gemini API Tool Retrieval: stop stuffing every tool into every prompt

Google has added Tool Retrieval to the Gemini API. Instead of hard-coding which functions a model may call and shipping every function definition in every request, the API now searches a registered function library, pulls in only the tools relevant to the user's intent, and executes them. That attacks the "fat prompt" problem directly: less context window consumed, lower token cost, and lower latency on agentic workflows such as refunds or database lookups. Developers keep control by registering which functions the model is allowed to see. Practical move: build one large internal service catalog and let retrieval pick the tool per request, but add error handling and a human-in-the-loop checkpoint for high-stakes actions, because a failed tool lookup breaks the whole chain.

2. Karpo Decision 31B and karpo-browser: about $1 for 40,000 decisions

MachinePulse AI open-sourced a fast decision model and its browser-agent framework. Karpo Decision 31B tops the 300-model Decision Index at 73.9, handles up to 255 candidate options per call, and answered 140,000+ public requests at a median 94 ms on a single RTX PRO 6000 - roughly $0.025 per 1,000 decisions, so about $1 covers ~40,000 choices. Its karpo-browser stack splits the work: a general model (System 2) plans while a specialist decision model (System 1) clicks, hitting 89% success at $0.096 per task on Browserbase Benchmark v2 - about 1.9x faster and one-thirteenth the model cost of Claude Fable 5.2 plus Claude Code. Practical move: route the frequent "which button / which tool / is it done?" judgements to a cheap decision model and reserve the general model for planning.

3. Reply.io Jason Harness: a nine-role outbound team on the AI you already pay for

On Nov 20 Reply.io released Jason Harness, a free MIT-licensed harness that runs inside an AI agent you already use - Claude Code or Codex - and turns it into a nine-role outbound team (Planner, Researcher, Copywriter, Personalizer, Critic, Responder, Analyst and more). It plans each contact individually from what was already sent and how they replied, instead of pushing everyone through one template. Because it uses your existing subscription, there is no separate model bill and no per-seat fee; playbooks are plain-text files, campaigns persist for weeks after the chat closes, and nothing is sent without your approval. It runs on Windows, Mac and Linux with no admin rights. Practical move: if you already pay for an agent, bolt on a free harness rather than buying another SaaS seat.

4. AWS Quick Flows: chat-built automations with fixed, audit-friendly steps

AWS shipped a broad Quick update on Nov 20: you can now build, run and refine a whole flow in chat with a live diagram beside it, combine agents, skills, tools and data, and add deterministic calculation steps so month-end numbers stay identical every run - a direct answer to LLM drift in finance work. Flows handle longer jobs and bigger data, keep running after you close the browser, and the new web app triages replies in a priority feed. New Meta ads and Amplitude MCP connectors plus multi-agent orchestration round it out; AWS cites roughly 80 hours saved on one use case. Practical move: encode the repeatable math as fixed steps, let agents draft, and keep a human approving before anything goes out.

5. Gemini for Mac: an agent that works in the background, not over your cursor

Google brought Computer Use to the Gemini app on macOS, and the design choice matters: rather than hijacking your cursor and screen, Gemini runs in an isolated background window, so you keep typing and meeting while it works in parallel. You get a live preview, can pause or intervene at any moment, grant per-app and per-file access on a least-privilege basis, and let it move data between a local spreadsheet and a web CRM. This ships alongside the free Gemini Tasks rollout in six countries. Practical move: favour background, API-driven agents over ones that simulate mouse clicks - they free your time instead of freezing your machine, and permission gates keep the risk bounded.

Automation tip of the day: Price the decision, not just the token. Let the API retrieve only the tools it needs (Gemini Tool Retrieval), send the high-frequency split-second choices to a sub-cent decision model (Karpo), reuse the AI subscription you already own instead of buying another seat (Jason Harness), and encode repeatable math as fixed steps with a human approving the send (AWS Quick). Then measure cost per completed task - that one number is the only proof your automation actually saves money.
