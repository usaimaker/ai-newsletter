Issue 2026-11-06 · Free AI kits, cheaper models, and automation that pays for itself

Five fresh, practical moves from this week that cut cost or save time - plus a tip you can apply today.

1. Friday: run Claude Code + Codex as a local agent crew

Open source · Nov 1

Friday is a new open-source orchestration layer (github.com/splashxmoon/friday) that runs Claude Code and Codex as collaborative "crews" on your own machine. You assign frontend to one agent, backend to another, and testing to a third; they share context through a knowledge graph and hand off work automatically. No mandatory cloud, config-driven, and you keep full control of the workflow.

Why it saves money: it is free and local-first, so there are no per-seat cloud fees and no vendor lock-in. You get each model's strength (Claude for architecture, Codex for fast generation) in one project, and you can compare outputs side by side before merging.

2. Revolut cut AI coding cost ~10x by dropping Claude for self-hosted models

Infra · Nov 3

Revolut replaced its Claude-based coding assistant with self-hosted open-source models running on 56 NVIDIA B200 GPUs serving ~2,000 engineers. The result: AI coding cost fell roughly 90%, and the bill is now fixed instead of a surprise invoice at month end. Frontier APIs became the exception, not the default.

Why it matters: for high-volume coding, self-hosting removes the "calls x unit price" multiplier that balloons agent bills. The trade-off is real hardware and ops cost, but it shows the ceiling on API spend is a choice, not a law of physics.

3. LinkedIn froze its AI cost at scale with distilled lightweight models

Cost control · Nov 4

LinkedIn's AI recruiting assistant now serves 25,000+ paying enterprises, yet its running cost has stayed flat year over year. The trick: knowledge-distilling frontier models into small, task-specific models for candidate search, ranking, and outreach messages - up to 67% cheaper than calling the frontier model directly. No extra GPU spend is planned through mid-2027.

Why it matters: distill frontier output for high-volume, narrow tasks and your cost curve decouples from usage growth. As usage climbs, the bill stays put.

4. Devloops: adversarial agent loops that humans still control

Safety · Nov 1

Devloops (github.com, open source) splits coding automation into three adversarial roles: a producer files issues, a worker implements them as PRs, and a skeptical gatekeeper tries to break each PR before approval. Agents are explicitly forbidden from merging - a human makes the final call, and security-sensitive paths get a "gatekeeper:needs-human" label. It is Python 3.8+ with no third-party deps, driven by GitHub CLI.

Why it saves time: fewer reverted merges and fewer security incidents. The adversarial review catches defects automatically, so humans only spend minutes on the key merge decision.

5. Cheapest automation models right now: GLM 4.7 Flash and MiMo V2.5

Pricing · Nov 4

Per current API pricing, GLM 4.7 Flash is the cheapest capable automation model at $0.06 in / $0.40 out per 1M tokens - open weights, tool-call support, 200k context. MiMo V2.5 carries the lowest official output price at $0.13 in / $0.27 out per 1M. Both beat frontier pricing by an order of magnitude for classification, extraction, and routing.

Why it matters: automation is where cost compounds. A model at $15/out per 1M running thousands of tasks a day gets expensive fast; routing bulk simple steps to a $0.27-$0.40/out model is the single biggest lever.

Automation tip of the day

Build a model ladder with a kill switch. Route high-volume, simple steps (classify, extract, route) to the cheapest open-weights model - GLM 4.7 Flash or MiMo V2.5. Reserve frontier models for hard reasoning only. Put a hard per-run token budget and a kill switch (like the agent kill switch CrowdStrike just shipped) on every loop so a runaway agent cannot blow the monthly bill. Cache proven workflows so repetitive jobs skip re-reasoning entirely.
