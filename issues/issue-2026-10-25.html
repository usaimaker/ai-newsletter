Workato opens its enterprise automation engine with 50,000 free credits

AgentsFree tier

Workato launched a self-serve tier in Singapore on October 21, and it is one of the more generous entries in this year’s agent land-grab: no credit card, 50,000 one-time credits, and access to the same governed execution engine that runs recipes for more than half of the Fortune 500. That includes AI agents (they call them Genies), Enterprise MCP servers, workflow orchestration and API management. The catch is structural rather than hidden — the credits do not renew, and every action burns them at a different rate, so you cannot calculate your runway until you start building. Paid plans begin at 75 dollars per month for 2,500 credits.

Practical read: if you run a consultancy or a small operational team, this is the cheapest way to prototype genuinely governed automation — approval steps, audit trails, connector management — before committing budget. Build the recipe, measure the credit burn over two weeks, then decide. Check data residency before you point it at customer records; Workato has not published a country-by-country processing map for every self-serve account.

Kavela: agent workflows with a reviewer on every single run

AgentsReliability

Kavela entered closed beta on October 23 with a pitch that targets the exact failure mode that kills agent projects in production: silent failure. You describe the workflow in plain language, Kavela draws the steps, and each execution runs on an isolated cloud computer with persistent file context. The distinguishing part is a reviewer that inspects the output against a checklist you define before the run is marked complete. Existing Claude or Codex subscriptions can be connected, and an MCP server promotes local sessions into repeatable cloud automations. Pricing is 30 dollars per month billed annually for 3,000 workflow minutes, with a 14-day free trial and no card required.

Why it matters for solo operators: the reviewer pattern is the difference between an automation you trust with client work and one you babysit. If you are already duct-taping check-the-output steps into your n8n flows, this is the concept to steal even if you never pay for the tool.

PlugVet grades 11,739 agent skills, plugins and MCP servers A through F

SecurityDirectory

Published to Show HN on October 23, PlugVet is an independent directory that assigns hygiene grades to Claude Code skills, Cursor and Codex plugins, and MCP servers — showing the checks behind each grade and the assessment date. It has graded 11,739 entries so far, holds F-graded entries back rather than publishing them, and states plainly that a grade is a hygiene check rather than a security guarantee. Browsing is free.

Use it as a first-pass filter before you install anything into an agent that touches real credentials or production data. It will not replace reading the source, but it removes most of the obvious junk in about ten seconds.

Vericto blocks destructive SQL from agents at the database wire protocol

SecurityDatabases

Vericto is a SQL proxy that sits between clients (including AI agents) and a PostgreSQL or MySQL database on the native wire protocol. It parses every statement into an AST, checks it against your rules, then either forwards it or returns a normal SQL error — for example refusing a DELETE with no WHERE clause. Integration is a host and port change in your connection string. It shipped v4.16.0 on October 24 and is source-available under FSL-1.1-ALv2: free to self-host, including in commercial production, with each release converting to Apache-2.0 after two years.

This is the layer most agent stacks are missing. Prompt-level guardrails are advisory; a wire-protocol parser is enforceable, and it keeps working when someone swaps the model.

Corgi multiplexes Claude Code, Codex, Pi and OpenCode in one terminal

Developer tools

Also from October 23, Corgi is a terminal multiplexer that shows what each coding agent is doing, which ones are waiting on input, and a running activity feed — with F1 jumping to the next unread agent. It unifies launching sessions across multiple accounts, adds session search and resume, tracks per-workspace CPU, memory and GPU, and uses a cheap model to label links, worktrees and activity. Free to install via script on macOS, Linux and WSL.

Automation tip of the day
Split your agent spend by reversibility, not by task size. Route anything cheap to redo — lead triage, transcript summaries, first drafts, classification — to a mini model around 0.75 dollars per million input tokens, and reserve frontier models for the irreversible steps like sending client-facing output or writing to production. Add prompt caching on whatever context your agent resends every turn. Teams that make this split usually cut the monthly bill by more than half without a visible quality drop, because most steps in an agent loop were never worth the expensive model.
