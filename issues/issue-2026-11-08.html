AI Automation Daily

Sunday, November 8, 2026 · 5 fresh, practical AI-automation updates

This week the theme is unmistakable: agents are getting cheaper to run and easier to own. From a fully open-source self-hosted coding agent to a tiny decision model that cut one company's bill by 97%, the wins below are about money and time — not benchmarks.

1. DeepSeek Super-Agent goes open-source (and free to self-host)

Open-source · Cost

Released November 1 under the MIT license as dsh-superagent-prototype, DeepSeek's Super-Agent watches developer group chats and proactively opens draft PRs — an OS-inspired Router coordinates ephemeral Worker nodes in isolated worktrees. Because it runs on DeepSeek's open weights on your own infrastructure, marginal cost per suggestion approaches zero. DeepSeek estimates its MoE architecture runs up to 80% cheaper than proprietary per-token coding tools like Claude Code.

2. Ragic cuts AI classification cost 97–98% with auto-routed tiny models

Money-saver

Cloud database platform Ragic (Nov 5) now auto-selects TypeSafe AI's Jev decision model for qualifying classification tasks instead of a general-purpose LLM. No code, no manual model picking. One customer's tracking agent had burned ~$200/month on Gemini Flash across 10,000+ runs; routing those decisions to Jev drops the same workload to well under $1/month. The lesson scales to any repetitive tagging, triage, or routing automation.

3. Claude Code slashes background-subagent token use up to 63%

Claude · Cost

Anthropic's November 5–6 update batches background tasks and compresses repeated codebase context with CodeDict, cutting token quota usage by as much as 63%. Field reports put continuous background CRM checks and webhook monitoring at under ~₱250/month (roughly $4) in raw API cost — turning "always-on agents" from a budget fear into a rounding error.

4. AWS prompt caching for OpenAI models on Bedrock trims agent loops

AWS · Cost

Agents routinely resend the same background context on every step, which quietly multiplies both cost and latency. AWS published a prompt-caching pattern for OpenAI models on Amazon Bedrock that stops the resend waste — a single lever that pays off the moment an agent runs more than a handful of steps per task.

5. xAI launches Shared Bots to automate the sales deal cycle

Sales · Time

xAI shipped Shared Bots for sales: three named teammates — Account Intel Bot, Quote Bot, and Deal Bot — that research accounts, prepare quotes, and track deals across a whole team. Packaging agents as shared "teammates" turns the deal cycle into background automation instead of manual rep work.

Automation tip of the day

Route every repetitive classification, extraction, or routing step to the smallest viable model — or a purpose-built decision model like Jev — and switch on prompt caching wherever an agent resends the same context. Combined, real teams report 63–98% cost cuts with zero quality loss on easy steps. Add a per-run token budget and a kill switch so a runaway loop can never silently drain the bill.
