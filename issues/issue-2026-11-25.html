AI Automation Daily - November 25, 2026

Today's theme: the bill comes from the loop, not the token. Five fresh developments that cut agent cost by compressing round trips, moving routine work to local models, and putting hard caps around runaway spends. Vendor numbers are flagged as claims, not verified results.

1. Cognition ships SWE-2.1 and a 10x faster Lightning variant, free for two weeks

On Nov 24 Cognition released SWE-2.1, trained with pure reinforcement learning on Moonshot's open-weight Kimi K3 inside a 250k-token context with up to three compactions (about 1M tokens total). Its own scoreboard puts FrontierCode 2.0 at 41.3 and Terminal-Bench 4.1 at 50, up from 24.1 and 24.2 for SWE-2. Paired with Cerebras, SWE-2.1 Ultrafast runs at ten times production token speed, and Lightning is free through Dec 8, 2026 for Devin Pro, Max and Teams users. No per-token API price has been published yet. Practical move: use the free window to benchmark the fast variant on your own repo before committing, and do not budget around unpublished pricing.

2. PrismML fits a 27B coding agent into 5.9 GB, free under Apache 2.0

Also on Nov 24, Ternary Bonsai 2.5 27B upgraded PrismML's local agent model. Built on Qwen 3.8 27B with ternary weights, it occupies just 5.9 GB of memory and runs on NVIDIA and Intel GPUs through llama.cpp and on Mac, iPhone and iPad through MLX. Vendor benchmarks put agentic coding average at 54.2 (from 37.9) and tool-calling average at 82.2 (from 60.2), with the stated focus on recovering from failed tool calls and cutting pointless repetition. Practical move: a local model means zero per-token cost and no client data leaving the device. A sensible split is local for tests, file conversions and confidential documents, cloud for genuinely complex design work.

3. Coding agents finally get daily caps and a bill tied to the pull request

Reporting on Nov 19 shows the control layer catching up. Snowflake says per-user quotas in its Cortex AI Gateway cut AI costs 16% after an engineer's internal Slack bots spent 1,100 dollars in a single day; the quotas block requests within minutes and daily limits work better than monthly ones. LangSmith now links GitHub pull requests and GitLab merge requests to agent threads so teams can compare cost per merged change, in public beta across Claude Code, Codex, Cursor and Copilot. Qodo auto-approves low-risk pull requests and withdraws approval if a new commit changes the change. Practical move: set a daily per-user ceiling before the spend happens, and track cost per completed change rather than one opaque monthly token bill.

4. Cheap-first routing cuts cost 2.6x, but only if the escalation rate stays low

Abacus AI's routing week (Nov 18-19) put model routing firmly in the cost layer: xHigh, a Frontier Model Router, and an open-source Smaug-Uncensored 27B release. Independent evidence is more useful than the vendor scores: the open-source ACRouter project reports a 2.6x reduction, 13.21 dollars versus 34.02 on Opus alone. The critical caveat is that routing only saves money when the cheap model succeeds most of the time: log the escalation rate, and if it climbs above roughly 20%, the router is buying retries, not savings. Practical move: reproduce the pattern in any workflow tool - classify the task, try the cheap model first, escalate only on failure or low confidence, cap spend per route, and log every decision. Keep human approval on anything irreversible.

5. Self-healing agents find 600 performance root causes in three months

OpenAI detailed Performance Factory this week: Codex agents automatically discover, diagnose and help fix regressions in ChatGPT performance, tracking more than 1,700 investigations and locating over 600 root causes in three months, around 17 automatic investigations a day without engineers on watch. A sample of 100 suggestions was about 70% accurate, with the rest needing rework, so the system adds an adversarial second session whose job is to try to overturn the first conclusion. Practical move: copy the verification structure, not just the automation. Give a separate check the explicit task of disproving a result before it reaches production, and treat a self-reported success rate as a starting hypothesis.

Automation tip of the day: price the task, not the token

A workflow plans, calls tools, re-reads context and retries, so the cost lives in round trips. Four moves that cost nothing to try: (1) use free evaluation windows to benchmark a faster model on your own workload before paying; (2) push routine, repetitive and confidential work to a local model with no per-token fee; (3) try cheap-first routing with a logged escalation rate and a hard budget cap per route; (4) put a daily per-user limit, an adversarial verifier and a kill switch around any loop that can spend or act on its own. Judge every vendor savings figure against your own cost per completed task.
